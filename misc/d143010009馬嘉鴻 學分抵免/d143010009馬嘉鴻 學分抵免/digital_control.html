課程概述 / DescriptionDescription

Since almost every engineering branch (control, signal processing, communications, dynamic system analysis, …) uses computers as their tools to handle the information, knowledge of digital system (or discrete-time system) becomes fundamental for every engineer. This course will introduce the basic skills required for the analysis and control of such systems. It is a course suitable for students who have taken the Automatic Control course. This course is mainly of undergraduate level, but is also suitable for graduate students who are not familiar with digital control.

課程目標 / Main TopicsMain Topics

  1. Z-transform
  2. Discrete-time model of sampled system
  3. Sampling theorem
  4. State-space control
  5. Discrete transfer function control
  6. Optimal control and optimal observer
