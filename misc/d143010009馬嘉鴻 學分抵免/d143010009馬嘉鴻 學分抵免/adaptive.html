課程概述 / Course DescriptionCourse Description

Requisite: Automatic Control, and Digital Control. This course provides a broad introduction to adaptive control techniques and practical implementations. This course covers adaptive control theories for deterministic and stochastic* systems, including recursive system identification, self-tuning regulator, model-reference adaptive system, auto-tuning, gain scheduling*, and adaptive control with lattice filter. (*optional)

課程目標 / Course ObjectivesCourse Objectives

The primary goal of this introductory course is to help students become knowledgeable designers of adaptive control systems. A moderate amount of simulations and experiments are associated with Matlab/Simulink toolboxes.
