Image-Reject Diode Mixer
slide 30/31 — how two 90° hybrids separate USB and LSB into different IF ports

RF 上下旁帶 → 兩個獨立的 IF 輸出，靠 RF 端與 IF 端各一個 90° hybrid 的相位魔術

為什麼需要 image-reject mixer？

在下變頻接收機裡，RF 訊號跟 LO 混頻後會產生兩個 IF 候選：

$$\omega_{IF} = |\omega_{RF} - \omega_{LO}|$$

這意味著兩個不同的 RF 頻率 $\omega_{LO}+\omega_{IF}$（USB, upper sideband）跟 $\omega_{LO}-\omega_{IF}$（LSB, lower sideband）會被混到同一個 IF 頻率。其中一個是「想要的訊號」，另一個是「鏡像 (image)」。

傳統做法：用 RF 濾波器擋掉 image，但...
當 IF 很低（例如幾 MHz）時，RF 濾波器需要極窄頻、高 Q —— 在 GHz 級的 RF 上幾乎做不出來。這時就需要 image-reject mixer：不靠濾波，而是用相位魔術把 USB 跟 LSB 路由到不同的輸出端口，你可以挑一個用。

拓樸拆解

① 左邊 90° RF hybrid：把 RF 訊號分相注入兩個 mixer

  • Port 1：RF input
  • Port 2 → $v_{RF}^A$（送到上面的 mixer A）— 相位差 $-90°$
  • Port 3 → $v_{RF}^B$（送到下面的 mixer B）— 相位差 $-180°$
  • Port 4：以 $Z_0$ 終結（不接訊號）

② 兩顆 mixer（diode 環）：各自跟同一個 LO 混頻

兩個 mixer 都吃同樣的 LO 訊號 $V_{LO}\cos\omega_{LO}t$，但 RF 端是相位差 $90°$ 的兩個版本。

③ 兩個 LPF：濾掉和頻和倍頻，留下 IF

每個 mixer 出來都有 $\omega_{RF}\pm\omega_{LO}$ 等成份，LPF 把和頻 $\omega_{RF}+\omega_{LO}$ 擋掉，留下差頻 $|\omega_{RF}-\omega_{LO}|=\omega_{IF}$。

④ 右邊 90° IF hybrid：再做一次 90° 移相，做相位相干干涉

關鍵就在這裡 — USB 跟 LSB 經過兩次 $90°$ 移相累積後相位不同，在這個 hybrid 的兩個輸出埠分別建設性疊加或破壞性對消，因此被路由到不同的輸出。

小訊號分析（為什麼 USB 跟 LSB 會分到不同埠）

Step 1 — RF 輸入含有 USB + LSB 兩個成份

$$v_{RF}(t) = \underbrace{V_U\cos(\omega_{LO}+\omega_{IF})t}_{\text{RF-USB}} + \underbrace{V_L\cos(\omega_{LO}-\omega_{IF})t}_{\text{RF-LSB}}$$

假設這兩個 RF 成份都會打到 mixer。要看看最終誰跑到哪個 IF 輸出。

Step 2 — 過 90° RF hybrid 後的兩條 RF 路徑

RF 由 port 1 進入，到 port 2 ($v_{RF}^A$) 的相位是 $-90°$，到 port 3 ($v_{RF}^B$) 的相位是 $-180°$：

$$\begin{aligned} v_{RF}^A(t) &= \tfrac{1}{\sqrt{2}}\bigl[V_U\cos((\omega_{LO}+\omega_{IF})t - 90°) + V_L\cos((\omega_{LO}-\omega_{IF})t - 90°)\bigr] \\ &= \tfrac{1}{\sqrt{2}}\bigl[V_U\sin(\omega_{LO}+\omega_{IF})t + V_L\sin(\omega_{LO}-\omega_{IF})t\bigr] \\[4pt] v_{RF}^B(t) &= \tfrac{1}{\sqrt{2}}\bigl[V_U\cos((\omega_{LO}+\omega_{IF})t - 180°) + V_L\cos((\omega_{LO}-\omega_{IF})t - 180°)\bigr] \\ &= -\tfrac{1}{\sqrt{2}}\bigl[V_U\cos(\omega_{LO}+\omega_{IF})t + V_L\cos(\omega_{LO}-\omega_{IF})t\bigr] \end{aligned}$$

注意：USB 跟 LSB 走的是同一條 hybrid 路徑，所以這裡兩者多 $-90°$（或多 $-180°$）的相位完全一樣。USB/LSB 的差別還沒展現出來 — 要等到 mixer 跟 LO 相乘後才會。

Step 3 — Mixer 跟 LO 相乘，LPF 留下 IF

每個 mixer 把 RF 跟 LO ($V_{LO}\cos\omega_{LO}t$) 相乘。用積化和差：

$$\cos A\cdot \cos B = \tfrac{1}{2}[\cos(A-B)+\cos(A+B)]$$ $$\sin A\cdot \cos B = \tfrac{1}{2}[\sin(A-B)+\sin(A+B)]$$

LPF 擋掉和頻（$A+B$ 約等於 $2\omega_{LO}$）、只留下差頻。代入後：

$$v_{IF}^A(t) = \frac{K V_{LO}}{2\sqrt{2}}\bigl[\underbrace{V_U\sin(+\omega_{IF}t)}_{\text{from USB}} + \underbrace{V_L\sin(-\omega_{IF}t)}_{\text{from LSB}}\bigr] = \frac{K V_{LO}}{2\sqrt{2}}(V_U - V_L)\sin\omega_{IF}t$$
$$v_{IF}^B(t) = -\frac{K V_{LO}}{2\sqrt{2}}\bigl[V_U\cos\omega_{IF}t + V_L\cos\omega_{IF}t\bigr] = -\frac{K V_{LO}}{2\sqrt{2}}(V_U + V_L)\cos\omega_{IF}t$$

關鍵：USB 經 mixer 後保留正的 $\omega_{IF}$ 相位；LSB 因為頻率比 LO 低，混完後變成負的 $\omega_{IF}$ 相位。$\sin(-x) = -\sin x$，所以路徑 A 上 USB 與 LSB 變成相減。路徑 B 則是相加。

Step 4 — 相量表示 (phasor form)

$$V_{IF}^A = \frac{-jKV_{LO}}{2\sqrt{2}}(V_U - V_L), \qquad V_{IF}^B = \frac{-KV_{LO}}{2\sqrt{2}}(V_U + V_L)$$

Step 5 — 過 90° IF hybrid 做最後一次干涉

IF hybrid 的兩個輸出端口 $V_1, V_2$ 分別是兩個輸入經過 $-90°$ 與 $-180°$ 移相後的和：

$$\begin{aligned} V_1 &= -j\tfrac{V_{IF}^A}{\sqrt{2}} - \tfrac{V_{IF}^B}{\sqrt{2}} = \frac{K V_{LO} V_L}{2}\\[2pt] V_2 &= -\tfrac{V_{IF}^A}{\sqrt{2}} - j\tfrac{V_{IF}^B}{\sqrt{2}} = \frac{j K V_{LO} V_U}{2} \end{aligned}$$

展開後（代入 step 4 的 $V_{IF}^A, V_{IF}^B$）就會發現 — $V_U$ 在 $V_1$ 對消、只剩 $V_L$；$V_L$ 在 $V_2$ 對消、只剩 $V_U$。轉回時域：

$$v_1(t) = \frac{K V_{LO} V_L}{2}\cos\omega_{IF}t \quad\Rightarrow\quad \text{IF-LSB (只有 LSB)}$$ $$v_2(t) = -\frac{K V_{LO} V_U}{2}\sin\omega_{IF}t \quad\Rightarrow\quad \text{IF-USB (只有 USB)}$$
這就是 image rejection 的相位魔術
USB 走 RF→A 路徑跟 RF→B 路徑時都各加了 90°；經 IF hybrid 後在 $V_2$ 兩條路徑同相相加（建設性）、在 $V_1$ 兩條路徑反相相消（破壞性）→ USB 只跑到 $V_2$。 LSB 因為 $\omega_{IF}$ 的「方向」相反，相位累積跟 USB 剛好差 $180°$，所以剛好走相反路 → LSB 只跑到 $V_1$。

實務問題與限制

項目說明
影像抑制度典型 ~20–30 dB（取決於兩條 mixer 路徑的振幅/相位匹配）。要達到 40+ dB 需要 trim 或 calibration。
製造困難IF 頻率通常很低（幾 MHz ~ 數十 MHz），但要做低頻 90° hybrid 很困難 — 集中元件 (LC) 的精度有限，分散元件 ($\lambda/4$) 在低頻又會太大。這是 image-reject mixer 在低 IF 下的主要限制。
RF 端的優勢RF 端 hybrid 在 GHz 級容易做（branch-line、Lange coupler 都可以），不是瓶頸。
轉換損失因為訊號要 ×$\tfrac{1}{\sqrt{2}}$ 分配兩次，總損失約 6 dB 比單一 mixer 多。
適用場景當 IF 太低、RF 預選濾波器做不到夠窄時，唯一選擇。常見於通訊接收機（GSM/LTE）、雷達、頻譜儀。

反向用：SSB modulator (上變頻)

把整顆電路反過來用：

  • 從 $v_1$ 端注入 IF 訊號 → 只輸出 RF-LSB（鏡像被天生抑制）
  • 從 $v_2$ 端注入 IF 訊號 → 只輸出 RF-USB

這就是單邊帶調變器（SSB modulator） — 不需要外加帶通濾波就能選擇要發射 USB 還是 LSB，傳統廣播、業餘無線電發射機常用。

三句話帶走

  1. RF 跟 LO 混頻時 USB 跟 LSB 會折到同一個 $\omega_{IF}$ — 這就是「鏡像問題」。Image-reject mixer 不靠濾波，而靠相位干涉把它們分開。
  2. 兩個 90° hybrid（RF 端 + IF 端）讓 USB 跟 LSB 累積不同的相位，在 IF 兩個輸出端口分別建設性/破壞性疊加 → 一個輸出純 USB、一個輸出純 LSB。
  3. 主要瓶頸是 IF hybrid 在低頻難做。要達 40+ dB 影像抑制需精密匹配；總損失約多 6 dB；反向用則變成 SSB modulator。
