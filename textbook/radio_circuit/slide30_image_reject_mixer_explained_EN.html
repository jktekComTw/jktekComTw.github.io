Image-Reject Diode Mixer
slide 30/31 — how two 90° hybrids separate USB and LSB into different IF ports

RF upper and lower sidebands → two independent IF outputs, thanks to the phase magic of one 90° hybrid at the RF end and another at the IF end

Why do we need an image-reject mixer?

In a downconverting receiver, mixing the RF signal with the LO produces two candidate IFs:

$$\omega_{IF} = |\omega_{RF} - \omega_{LO}|$$

This means two different RF frequencies, $\omega_{LO}+\omega_{IF}$ (USB, upper sideband) and $\omega_{LO}-\omega_{IF}$ (LSB, lower sideband),are mixed down to the same IF frequency. One of them is the wanted signal, the other is the image.

The traditional approach: block the image with an RF filter — but…
When the IF is low (a few MHz, say), the RF filter has to be extremely narrowband and high-Q — which is all but impossible to build at GHz RF. That is exactly where you need the image-reject mixer: rather than filtering, it usesphase magicto route the USB and the LSB todifferent output ports, so you can pick whichever one you want.

Breaking down the topology

① The 90° RF hybrid on the left: splits the RF signal in quadrature into the two mixers

  • Port 1: RF input
  • Port 2 → $v_{RF}^A$ (feeding mixer A above) — phase shift $-90°$
  • Port 3 → $v_{RF}^B$ (feeding mixer B below) — phase shift $-180°$
  • Port 4: terminated in $Z_0$ (no signal connected)

② The two mixers (diode rings): each mixes against the same LO

Both mixers are fed the same LO signal $V_{LO}\cos\omega_{LO}t$, but their RF ports see two versions $90°$ apart in phase.

③ The two LPFs: strip off the sum and harmonic products, leaving the IF

Every mixer output contains components at $\omega_{RF}\pm\omega_{LO}$ and beyond; the LPF blocks the sum term $\omega_{RF}+\omega_{LO}$ and keeps the difference $|\omega_{RF}-\omega_{LO}|=\omega_{IF}$.

④ The 90° IF hybrid on the right: one more 90° phase shift, producingcoherent phase interference

This is where the trick happens — after the USB and LSB have accumulatedtwo $90°$ shifts their phases differ, so at the two output ports of this hybrid they respectively undergoconstructive additionordestructive cancellation, and are therefore routed to different outputs.

Small-signal analysis (why the USB and LSB end up at different ports)

Step 1 — the RF input contains both a USB and an LSB component

$$v_{RF}(t) = \underbrace{V_U\cos(\omega_{LO}+\omega_{IF})t}_{\text{RF-USB}} + \underbrace{V_L\cos(\omega_{LO}-\omega_{IF})t}_{\text{RF-LSB}}$$

Assume both RF components reach the mixer. Let us track which one ends up at which IF output.

Step 2 — the two RF paths after the 90° RF hybrid

The RF enters at port 1; the phase at port 2 ($v_{RF}^A$) is $-90°$ and the phase at port 3 ($v_{RF}^B$) is $-180°$:

$$\begin{aligned} v_{RF}^A(t) &= \tfrac{1}{\sqrt{2}}\bigl[V_U\cos((\omega_{LO}+\omega_{IF})t - 90°) + V_L\cos((\omega_{LO}-\omega_{IF})t - 90°)\bigr] \\ &= \tfrac{1}{\sqrt{2}}\bigl[V_U\sin(\omega_{LO}+\omega_{IF})t + V_L\sin(\omega_{LO}-\omega_{IF})t\bigr] \\[4pt] v_{RF}^B(t) &= \tfrac{1}{\sqrt{2}}\bigl[V_U\cos((\omega_{LO}+\omega_{IF})t - 180°) + V_L\cos((\omega_{LO}-\omega_{IF})t - 180°)\bigr] \\ &= -\tfrac{1}{\sqrt{2}}\bigl[V_U\cos(\omega_{LO}+\omega_{IF})t + V_L\cos(\omega_{LO}-\omega_{IF})t\bigr] \end{aligned}$$

Note that the USB and the LSB travelalong the same hybrid path, so the extra $-90°$ (or $-180°$) that each picks up here isexactly the same. The difference between USB and LSB has not appeared yet — it only emerges once the mixer multiplies them by the LO.

Step 3 — the mixer multiplies by the LO, the LPF keeps the IF

Each mixer multiplies the RF by the LO ($V_{LO}\cos\omega_{LO}t$). Using the product-to-sum identity:

$$\cos A\cdot \cos B = \tfrac{1}{2}[\cos(A-B)+\cos(A+B)]$$ $$\sin A\cdot \cos B = \tfrac{1}{2}[\sin(A-B)+\sin(A+B)]$$

The LPF blocks the sum term ($A+B$, roughly $2\omega_{LO}$) and keeps only the difference. Substituting:

$$v_{IF}^A(t) = \frac{K V_{LO}}{2\sqrt{2}}\bigl[\underbrace{V_U\sin(+\omega_{IF}t)}_{\text{from USB}} + \underbrace{V_L\sin(-\omega_{IF}t)}_{\text{from LSB}}\bigr] = \frac{K V_{LO}}{2\sqrt{2}}(V_U - V_L)\sin\omega_{IF}t$$
$$v_{IF}^B(t) = -\frac{K V_{LO}}{2\sqrt{2}}\bigl[V_U\cos\omega_{IF}t + V_L\cos\omega_{IF}t\bigr] = -\frac{K V_{LO}}{2\sqrt{2}}(V_U + V_L)\cos\omega_{IF}t$$

The key point: after mixing, the USB retains a positive $\omega_{IF}$ phase; the LSB, being lower in frequency than the LO, comes out with anegative $\omega_{IF}$ phase. Since $\sin(-x) = -\sin x$, on path A the USB and LSB end upsubtracting, while on path B they add.

Step 4 — phasor form

$$V_{IF}^A = \frac{-jKV_{LO}}{2\sqrt{2}}(V_U - V_L), \qquad V_{IF}^B = \frac{-KV_{LO}}{2\sqrt{2}}(V_U + V_L)$$

Step 5 — the 90° IF hybrid performs one last interference

The two output ports $V_1, V_2$ of the IF hybrid are the sums of the two inputs after $-90°$ and $-180°$ phase shifts respectively:

$$\begin{aligned} V_1 &= -j\tfrac{V_{IF}^A}{\sqrt{2}} - \tfrac{V_{IF}^B}{\sqrt{2}} = \frac{K V_{LO} V_L}{2}\\[2pt] V_2 &= -\tfrac{V_{IF}^A}{\sqrt{2}} - j\tfrac{V_{IF}^B}{\sqrt{2}} = \frac{j K V_{LO} V_U}{2} \end{aligned}$$

Expanding (substituting $V_{IF}^A, V_{IF}^B$ from step 4) shows that $V_U$ cancels at $V_1$, leaving only $V_L$, while $V_L$ cancels at $V_2$, leaving only $V_U$. Back in the time domain:

$$v_1(t) = \frac{K V_{LO} V_L}{2}\cos\omega_{IF}t \quad\Rightarrow\quad \text{IF-LSB (LSB only)}$$ $$v_2(t) = -\frac{K V_{LO} V_U}{2}\sin\omega_{IF}t \quad\Rightarrow\quad \text{IF-USB (USB only)}$$
This is the phase magic behind image rejection
On both the RF→A and the RF→B path the USB picks upan extra 90° each; after the IF hybrid the two paths add in phase at $V_2$ (constructive) and cancel in antiphase at $V_1$ (destructive) → the USB goes only to $V_2$. Because the “direction” of $\omega_{IF}$ is reversed for the LSB, its accumulated phase differs from the USB's by exactly $180°$, so it takes precisely the opposite route → the LSB goes only to $V_1$of the image-reject mixer at low IF.

Practical issues and limitations

ItemNotes
Image rejectionTypically ~20–30 dB (set by the amplitude/phase match of the two mixer paths). Reaching 40+ dB requires trimming or calibration.
Manufacturing difficultyThe IF is usually very low (a few MHz to a few tens of MHz), yet building alow-frequency 90° hybrid is hard — lumped elements (LC) have limited accuracy, while distributed elements ($\lambda/4$) become far too large at low frequencies. This is themain limitationof the image-reject mixer at low IF.
The advantage at the RF endThe RF-end hybrid is easy to build at GHz frequencies (branch-line or Lange couplers both work), so it is not the bottleneck.
Conversion lossBecause the signal is split by ×$\tfrac{1}{\sqrt{2}}$ twice, the total loss is about 6 dB more than for a single mixer.
When to use itThe only option when the IF is too low for the RF preselect filter to be made narrow enough. Common in communication receivers (GSM/LTE), radar and spectrum analysers.

Running it backwards: an SSB modulator (upconversion)

Use the whole circuitin reverse:

  • Inject the IF signal at $v_1$ → only RF-LSB comes out (the image is inherently suppressed)
  • Inject the IF signal at $v_2$ → only RF-USB comes out

This is precisely asingle-sideband modulator(SSB modulator) — you can choose whether to transmit USB or LSB without any additional bandpass filter, which is why it is a staple of traditional broadcast and amateur-radio transmitters.

Three sentences to take away

  1. When the RF mixes with the LO, the USB and the LSB fold onto the same $\omega_{IF}$ — that is the image problem. An image-reject mixer separates them not by filtering but byphase interference.
  2. Two 90° hybrids (one at the RF end, one at the IF end) give the USB and the LSB different accumulated phases, so at the two IF output ports they add constructively and destructively respectively → one output is pure USB, the other pure LSB.
  3. The main bottleneck is that the IF hybrid is hard to build at low frequencies. Reaching 40+ dB of image rejection demands precise matching; the total loss is about 6 dB higher; and run in reverse it becomes an SSB modulator.
