Smith Chart 上「三種圓」的差異

要看你說的是哪個「圓」 — Smith 圖上有三種不同的圓，常被混為一談。下面把它們的圓心位置、物理意義、設計用途整理清楚。

圓 1：constant-$|\Gamma|$ 圓（同心圓）

  • 圓心永遠在 Smith 圖中央
  • 半徑 = $|\Gamma|$
  • 物理意義：圓上每點有同樣的 VSWR / 回波損失
  • 用途：串聯傳輸線旋轉的軌跡（不改變 $|\Gamma|$，只改變相位）
  • 跟增益無關
▸ 如何得到這個圓？（點開展開）

只需一個輸入：一個阻抗（或反射係數）。流程如下：

三步驟

步驟 1 — 從阻抗 $Z$ 算出反射係數

給定任何阻抗 $Z$ 與參考阻抗 $Z_0 = 50\,\Omega$：

$$\Gamma = \frac{Z - Z_0}{Z + Z_0}$$

步驟 2 — 取模

$$|\Gamma| = \left|\frac{Z - Z_0}{Z + Z_0}\right|$$

這個數值就是圓的半徑（範圍 $0 \le |\Gamma| \le 1$）。

步驟 3 — 畫圓

以 Smith 圖中心（$\Gamma = 0$ 點，對應 $Z_0 = 50\,\Omega$）為圓心，畫出半徑 $|\Gamma|$ 的圓。

具體例子

設 $Z = 100 + j50\,\Omega$：

$$\Gamma = \frac{(100+j50) - 50}{(100+j50) + 50} = \frac{50+j50}{150+j50} \approx 0.4 + j0.2 = 0.447\angle 26.6°$$ $$\Rightarrow\;\; |\Gamma| = 0.447$$

→ 以原點為圓心、半徑 $0.447$ 畫圓，即得 $Z = 100+j50$ 對應的 constant-$|\Gamma|$ 圓。

物理意義 — 為什麼是「圓」而不是別的形狀

如果你接一段無耗的 50 Ω 傳輸線到負載 $Z$，沿著線走，每一點看到的阻抗都不一樣，但反射係數的大小不變，只有相位變：

$$\Gamma(\ell) = \Gamma_L \cdot e^{-j2\beta\ell}$$
  • $|\Gamma(\ell)| = |\Gamma_L|$ ← 模不變
  • $\angle\Gamma(\ell) = \angle\Gamma_L - 2\beta\ell$ ← 相位隨距離改變

複數座標下「模不變、相位變」的軌跡就是以原點為心的圓 — 這就是 constant-$|\Gamma|$ 圓的物理由來。

在下方互動圖裡

  1. 拉「起始 $|\Gamma_0|$」滑桿 → 改變圓的半徑
  2. 拉「起始 $\angle\Gamma_0$」滑桿 → 改變灰色起點在圓上的初始位置
  3. 拉「串聯線長 $\ell$」滑桿 → 藍色點沿圓順時針旋轉（toward generator）

不管怎麼拉，藍色點都不會離開那個圓，這就視覺化了「同 $|\Gamma|$ 圓」的存在。

互動：串聯線沿 constant-$|\Gamma|$ 圓旋轉

藍色軌跡 = 同心圓上的旋轉。注意 $|\Gamma|$、VSWR、回波損失三個量在過程中都不變。
▸ 為什麼是 $2\beta\ell$ 而不是 $\beta\ell$？（點開展開）

關鍵：$\Gamma$ 是「反射波 / 入射波」的比值 — 反射係數的相位包含往返兩段線的相位累積。

推導

無耗線上電壓由前進波（往負載）與反射波（往源端）疊加：

$$V^+(z) = V_0^+ e^{-j\beta z}, \qquad V^-(z) = V_0^- e^{+j\beta z}$$

在位置 $z$ 的局部反射係數：

$$\Gamma(z) = \frac{V^-(z)}{V^+(z)} = \frac{V_0^- e^{+j\beta z}}{V_0^+ e^{-j\beta z}} = \underbrace{\frac{V_0^-}{V_0^+}}_{=\,\Gamma_L\text{ 在 }z=0} \cdot e^{+j2\beta z}$$

設負載在 $z = 0$，往源端方向走距離 $\ell$（即 $z = -\ell$）：

$$\boxed{\;\Gamma(\ell) = \Gamma_L \cdot e^{-j2\beta\ell}\;}$$

物理直覺：往返兩段

  • 波從輸入端走到負載：累積相位 $\beta\ell$（一段）
  • 反射後從負載走回輸入端：再累積 $\beta\ell$（第二段）
  • 合計：$\Gamma$ 相位變化 $= 2\beta\ell$（一個往返）

對比：阻抗 $Z(\ell)$ 是「電壓 / 電流」的瞬時比，不是往返量，因此公式裡只出現 $\tan(\beta\ell)$、不是 $\tan(2\beta\ell)$。

換算成 $\lambda$ 單位

$\beta = 2\pi/\lambda$，所以：

$$2\beta\ell = 2 \cdot \frac{2\pi}{\lambda} \cdot \ell = 4\pi \cdot \frac{\ell}{\lambda} = 4\pi L$$

其中 $L = \ell/\lambda$ 是滑桿的值。對應到程式：

const ang1 = ang0 - 4*Math.PI*L; // 2βℓ = 4π·L

關鍵 $\ell$ 值

$\ell$$2\beta\ell$圓上旋轉
$\lambda/8$$90°$四分之一圈
$\lambda/4$$180°$半圈（阻抗反相，inverter）
$\lambda/2$$360°$整圈回到原位 — 這就是滑桿上限

$\lambda/2$ 整圈循環就是「傳輸線的 $\lambda/2$ 週期性」 — 同一線長加減 $\lambda/2$，阻抗與反射係數完全相同。

那為什麼 stub 公式是 $\tan(\beta\ell_s)$ 而不是 $\tan(2\beta\ell_s)$？

這是同一個物理事實，兩種域的表達：

表達方式角度原因
$\Gamma$ 旋轉（反射係數域）$2\beta\ell$$\Gamma = V^-/V^+$ 是兩個反向波的比，移動 $\ell$ 兩個波相位差 $2\beta\ell$
$\tan(\beta\ell)$（阻抗 / 導納域）$\beta\ell$$Z = V/I$ 是兩個波在同一點的疊加，化簡後因子 2 被三角恆等式吸收

驗證：用短路 stub 推一次看看。 短路時 $\Gamma_L = -1$，往源端走 $\ell_s$：

$$\Gamma_{\text{in}} = -e^{-j2\beta\ell_s}$$

把 $\Gamma_{\text{in}}$ 換成阻抗：

$$Z_{\text{in}} = Z_0\,\frac{1+\Gamma_{\text{in}}}{1-\Gamma_{\text{in}}} = Z_0\,\frac{1-e^{-j2\beta\ell_s}}{1+e^{-j2\beta\ell_s}}$$

用三角恆等式 $\dfrac{1-e^{-j2x}}{1+e^{-j2x}} = j\tan x$：

$$\boxed{\;Z_{\text{in}} = jZ_0\tan(\beta\ell_s)\;}$$

原本指數裡的 $2\beta\ell_s$ 在化簡時被吸收成 $\tan(\beta\ell_s)$ — 因子 2 並沒有消失，只是「藏」在三角恆等式裡。

記憶口訣

用哪個量用什麼角度
在 Smith 圖上轉圓（$\Gamma$ 域）$2\beta\ell$（往返）
算 stub 的 $b$、$x$（$Y$ / $Z$ 域）$\beta\ell$（單程）

看到 $\tan$ / $\cot$ 公式就是單程 $\beta\ell$；看到 $e^{-j(\cdot)}$ 旋轉就是往返 $2\beta\ell$。

一句話總結

$\Gamma$ 是往返量，旋轉角是 $2\beta\ell$。Smith 圖上「toward generator $\lambda/2$」走完整圈，就是這個 2 倍因子的直接結果。Stub 的 $\tan(\beta\ell_s)$ 其實也含這個 2 倍因子，只是被三角恆等式化掉，看起來像單程。

圓 2：constant-$G_S$ 圓（增益圓）

  • 圓心不在中央，在連接 $O$ 與 $S_{11}^*$ 的射線上
  • 由 $S_{11}$ 與目標 $G_S$ 一起決定（公式較複雜）
  • 物理意義：圓上每一點都產生同樣的源端增益 $G_S$
  • 用途：給你多個等效的 $\Gamma_s$ 候選位置選擇

$G_S$ 圓上的點代表什麼？

「$G_S$ 圓上面的點所代表的阻抗值」這個說法是對的 — 因為：

$G_S$ 圓上的位置$\Gamma_s$ 值對應 $z_s$
圓心點（最大增益）$S_{11}^*$$z_s = (1+S_{11}^*)/(1-S_{11}^*)$
圓上的其他點不同的 $\Gamma_s$不同的 $z_s$

所有這些點的 $\Gamma_s$ / $z_s$ 都不同，但給出同一個 $G_S$。 設計者可以從圓上挑一個方便實做的阻抗（避開太靠近 short / open、或避開穩定區外）。

圓 3：constant-$g$ 圓（等電導圓）

  • 圓心在 $(-0.5,\,0)$，半徑 $0.5$（指 $g=1$ 圓；其他 $g$ 值類似）
  • 物理意義：圓上每點有同樣的歸一化導納 (admittance)實部 $g$
  • 用途：並聯短截線軌跡 — 加入 $jb$ 沿 $g=$ 常數圓滑動
▸ 並聯開路短截線：$b = \tan(\beta\ell_s)$（點開展開）

推導

開路短截線的終端 $Z_L \to \infty$（斷路）。代入傳輸線輸入阻抗公式並取極限：

$$Z_{\text{in}} = Z_0 \cdot \frac{Z_L + j Z_0 \tan(\beta\ell_s)}{Z_0 + j Z_L \tan(\beta\ell_s)} \xrightarrow{Z_L\to\infty} \frac{Z_0}{j\tan(\beta\ell_s)} = -j Z_0 \cot(\beta\ell_s)$$
▸ 傳輸線輸入阻抗公式怎麼來的？（點開展開）

步驟 1 — 線上的電壓電流通解

無耗傳輸線上的電壓電流，由前進波 + 反射波疊加而成：

$$V(z) = V^+ e^{-j\beta z} + V^- e^{+j\beta z}$$ $$I(z) = \frac{V^+}{Z_0} e^{-j\beta z} - \frac{V^-}{Z_0} e^{+j\beta z}$$

座標系：設負載在 $z = 0$，輸入端在 $z = -\ell$。

步驟 2 — 在負載端套邊界條件

在 $z = 0$：

$$V(0) = V^+ + V^-, \qquad I(0) = \frac{V^+ - V^-}{Z_0}$$

負載阻抗 $Z_L = V(0)/I(0)$：

$$Z_L = Z_0 \cdot \frac{V^+ + V^-}{V^+ - V^-}$$

直接把 $V(0)$、$I(0)$ 相除就得到這條。分子是兩波電壓的和，分母是差 — 因為反射波往 $-z$ 方向跑，$I = V/Z_0$ 的關係對它要翻一個負號，所以 $I(0)$ 裡 $V^-$ 帶負號。

定義負載反射係數：

$$\Gamma_L = \frac{V^-}{V^+} = \frac{Z_L - Z_0}{Z_L + Z_0}$$

把上面 $Z_L$ 的分子分母都除以 $V^+$，可改寫成反射係數形式（與上式等價）：

$$Z_L = Z_0 \cdot \frac{1 + \Gamma_L}{1 - \Gamma_L}$$

步驟 3 — 計算輸入端阻抗

在 $z = -\ell$：

$$V(-\ell) = V^+\!\left[e^{+j\beta\ell} + \Gamma_L e^{-j\beta\ell}\right]$$ $$I(-\ell) = \frac{V^+}{Z_0}\!\left[e^{+j\beta\ell} - \Gamma_L e^{-j\beta\ell}\right]$$

兩者相除：

$$Z_{\text{in}} = Z_0 \cdot \frac{e^{+j\beta\ell} + \Gamma_L e^{-j\beta\ell}}{e^{+j\beta\ell} - \Gamma_L e^{-j\beta\ell}}$$

步驟 4 — 化簡（套入 $\Gamma_L$ 並用 Euler 公式）

代入 $\Gamma_L = (Z_L - Z_0)/(Z_L + Z_0)$，分子分母都乘以 $(Z_L + Z_0)$：

分子：

$$(Z_L + Z_0)e^{+j\beta\ell} + (Z_L - Z_0) e^{-j\beta\ell} = 2Z_L \cos(\beta\ell) + 2j Z_0 \sin(\beta\ell)$$

分母（類推）：

$$2Z_0 \cos(\beta\ell) + 2j Z_L \sin(\beta\ell)$$

代回後再把分子分母都除以 $\cos(\beta\ell)$：

$$\boxed{\,Z_{\text{in}} = Z_0 \cdot \frac{Z_L + j Z_0 \tan(\beta\ell)}{Z_0 + j Z_L \tan(\beta\ell)}\,}$$

特例驗證

情況代入結果
$\ell = 0$$\tan 0 = 0$$Z_{\text{in}} = Z_L$ ✓
$Z_L = Z_0$（匹配）分子 = $Z_0(1+j\tan)$$Z_{\text{in}} = Z_0$ ✓（線長無關）
$\ell = \lambda/4$$\tan(\pi/2)\to\infty$$Z_{\text{in}} = Z_0^2/Z_L$（impedance inverter）
$Z_L = 0$（短路）$Z_{\text{in}} = j Z_0 \tan(\beta\ell)$
$Z_L = \infty$（開路）$Z_{\text{in}} = -j Z_0 \cot(\beta\ell)$

最後兩個就是「短路 / 開路短截線」的特例 — 短截線公式都是這條主公式的子集。

核心物理

整條公式背後只有兩個事實：

  1. 線上的波是前進 + 反射兩個波的疊加（無耗線假設）
  2. 負載決定反射係數 $\Gamma_L$

加上三角恆等式整理出來，就是傳輸線最重要的公式之一。

純電抗（reactive）。取倒數成導納 (admittance)：

$$Y_{\text{in}} = \frac{1}{-j Z_0 \cot(\beta\ell_s)} = j Y_0 \tan(\beta\ell_s)$$

歸一化（除以 $Y_0$）：

$$y_{\text{stub}} = j\tan(\beta\ell_s) = jb \;\;\Longrightarrow\;\; \boxed{b = \tan(\beta\ell_s)}$$

$\beta$ 跟 $\ell_s$ 怎麼換成 $\lambda$ 單位

相位常數 $\beta = 2\pi/\lambda$，所以：

$$\beta\ell_s = 2\pi \cdot \frac{\ell_s}{\lambda}$$

例如 $\ell_s = 0.100\lambda$：$\beta\ell_s = 36°$，$b = \tan(36°) \approx 0.727$。

關鍵 $\ell_s$ 值的 $b$

$\ell_s$$\beta\ell_s$$b = \tan(\beta\ell_s)$物理
$0$$0°$$0$無作用（純粹是開路）
$\lambda/8$$45°$$+1$電容性 susceptance
$\lambda/4^-$$\to 90°^-$$\to +\infty$等效短路（impedance inverter）
$\lambda/4^+$$\to 90°^+$$\to -\infty$從另一邊跳到 $-\infty$
$3\lambda/8$$135°$$-1$電感性 susceptance
$\lambda/2$$180°$$0$$\lambda/2$ 週期，回到無作用

為何用「開路」而不是「短路」

  • PCB 製作容易：開路 = 線到此截止；短路 = 需要打 via 接地，多一道工序也增加寄生電感。
  • 覆蓋整段 susceptance：開路短截線從 $\ell_s = 0$ 到 $\lambda/4$ 可以提供 $b \in (0,+\infty)$，再到 $\lambda/2$ 可提供 $b \in (-\infty, 0)$，整個 susceptance 範圍都涵蓋。
  • 對應的短路短截線只是長度差 $\lambda/4$：$b_{\text{short}} = -\cot(\beta\ell_s)$，與開路在曲線上互相平移 $\lambda/4$。

互動：並聯開路短截線沿 $g=1$ 圓滑動

綠色軌跡 = $g=1$ 圓。短截線加入 $jb = j\tan(\beta\ell_s)$，把點從中央沿 $g=1$ 圓拉到外面。$g$ 始終 = 1，只有 $b$ 在變。
▸ 為什麼是 $g=1$？（點開展開）

不是只能用 $g=1$ — 是因為 demo 的起點是 Smith 圖中心（$y = 1$，$g = 1$）。並聯短截線只改變 $b$、不改變 $g$，所以從中心出發必然沿 $g=1$ 圓滑動。

物理規則

並聯加入一個純電納 $jb_{\text{stub}}$：

$$y_{\text{new}} = y_{\text{old}} + jb_{\text{stub}}$$

實部不變（$g$ 守恆），只有虛部改變：

$$g_{\text{new}} = g_{\text{old}}, \qquad b_{\text{new}} = b_{\text{old}} + b_{\text{stub}}$$

→ 點沿著「等 $g$ 圓」滑動，$g$ 等於多少由起點決定。

不同起點對應不同 $g$ 圓

起點 $y_0$起點所在的圓加入並聯 stub 後沿哪個圓走
$y_0 = 1$（中心）$g = 1$$g = 1$ ✓（demo 用這個）
$y_0 = 0.5 + j0.3$$g = 0.5$$g = 0.5$
$y_0 = 2 - j1$$g = 2$$g = 2$
$y_0 = 0.1 + j2$$g = 0.1$$g = 0.1$

在 demo 互動圖裡

  • $b$ 從 $0$ 增加到 $\tan(\beta\ell_s)$
  • 點沿 $g=1$ 圓向下滑（負虛部方向，因為 $b > 0$）
  • $g$ 始終 = 1，所以走在 $g=1$ 圓上 — 這是「起點剛好在 $g=1$ 圓上」的特例

一句話總結

「沿 $g=1$ 圓滑動」是 demo 起點選在 $y=1$ 的結果，不是並聯 stub 的本質。並聯 stub 的本質是「沿等 $g$ 圓滑動」，其中 $g$ 由起點決定。

圖 1 和圖 3 是同一個圓嗎？（阻抗 vs 導納 (admittance)視角）

常見的誤解：「圖 1（constant-$|\Gamma|$ 圓）和圖 3（constant-$g$ 圓）其實是同一個圓，只是一個從阻抗、一個從導納 (admittance)角度看而已。」這個說法不對。

三個圓對照

圓中心半徑圓上每點共通的是
圖 1：constant-$\|\Gamma\|$ 圓$(0,0)$$\|\Gamma\|$（變數）$\|\Gamma\|$（也就是 VSWR / RL）
阻抗系列：constant-$r$ 圓$\left(\dfrac{r}{r+1},\,0\right)$（偏右）$\dfrac{1}{r+1}$歸一化電阻 $r$
圖 3：constant-$g$ 圓$\left(-\dfrac{g}{g+1},\,0\right)$（偏左）$\dfrac{1}{g+1}$歸一化電導 $g$

圖 1 和圖 3 的位置、半徑、物理量都不一樣 — 它們是三個不同的圓家族。

你的直覺對應的其實是這個關係

同一個阻抗 $z$ 在 Smith 圖上，從阻抗角度和導納 (admittance)角度讀，會落在不同位置（差 180°），因為 $\Gamma_y = -\Gamma_z$。但 constant-$r$ 圓和 constant-$g$ 圓的「形狀結構」是鏡像對稱的：

對應關係Z-Smith 上長相Y-Smith 上長相
$r=1$ ↔ $g=1$圓心 $(+0.5,0)$，半徑 0.5圓心 $(-0.5,0)$，半徑 0.5
$r=2$ ↔ $g=2$圓心 $(+0.67,0)$，半徑 0.33圓心 $(-0.67,0)$，半徑 0.33

也就是說 — 把 Z-Smith 圖繞原點旋轉 180°就會變成 Y-Smith 圖。「圖 3 的 $g=1$ 圓」其實就是「Z-Smith 圖上的 $r=1$ 圓」翻過來而已。這個對應只限於阻抗系列圓 ↔ 導納 (admittance)系列圓，跟圖 1（同心圓）無關。

圖 1 跟阻抗 / 導納 (admittance)視角無關

constant-$|\Gamma|$ 圓（圖 1）的存在不需要區分阻抗或導納 (admittance)觀點 — 它就是「離 Smith 圖中心固定距離」的同心圓，定義純粹來自 $\Gamma$ 的模值。

不管你把該點解讀成 $z = 0.6 + j0.4$（阻抗）還是 $y = 1.143 - j0.742$（導納 (admittance)），它都在同一個 $\|\Gamma\|$ 圓上。

結論：
  • 圖 1 vs 圖 3：完全不同的圓，不是阻抗 / 導納 (admittance)兩種視角。
  • 圖 3 vs constant-$r=1$ 圓：才是「同一個結構，兩種視角」的關係（$\Gamma_y = -\Gamma_z$ 的鏡像）。

三種圓的一覽表

概念 圓心位置 點上同樣的東西 設計用途
constant-$|\Gamma|$ 圓 中央 $(0,0)$ VSWR、回波損失 串聯線旋轉軌跡

一句話總結

constant-$G_S$ 圓上每一點 = 一個候選 $(\Gamma_s, z_s)$ 組合，全部給同一個 $G_S$ 值。互動圖的 hover 功能就是讓你在這個圓上滑動，看不同位置對應的 $\Gamma_s$ 與 $z_s$ 是什麼。

常見混淆：「Γ 圓」這個說法有歧義 — 有人指 constant-$|\Gamma|$ 圓（圓心在中央），有人指 constant-$G_S$ 圓（圓心偏在一邊）。看到「Γ 圓」這三個字時，先確認對方說的是哪一個，可以省去很多誤會。

為什麼「圓的半徑 = 0 時 = 最大可用增益」？

▸ Maximum available power gain occurs when the radius of the constant input (or output) power gain circle is zero — why?

幾何直覺

constant-$G_P$（或 $G_A$）圓是所有能產生同一增益值的 $\Gamma_L$ 集合。圓上每一點代表一個不同的負載阻抗，但給出相同的功率增益。

把 $G_P$ 由小調大，看圓會怎麼變：

$G_P$ 值圓半徑意義
小大$\Gamma_L$ 選項很多 — 容易達成這個增益。
較大較小$\Gamma_L$ 選項變少 — 設計空間變窄。
$G_{P,\max}$0（一點）只剩唯一的 $\Gamma_L$ 能達到這個增益 — 即 simultaneous-conjugate-match $\Gamma_{ML}$。
超過 $G_{P,\max}$虛數 / 負數沒有任何實際 $\Gamma_L$ 能產生這麼大增益 — 物理上不可能。

所以「半徑 = 0」就是可達與不可達的分界。剛好低於它，有一個很小的圓（很多選項都擠在 $\Gamma_{ML}$ 附近）；剛好等於它，只有一個點；超過它，圓不存在。

數學推導

operating-gain 圓的半徑公式（$\Gamma_L$ 平面）：

$$R_P \;=\; \frac{\sqrt{1 - 2K|S_{12}S_{21}|\,g_P + |S_{12}S_{21}|^2 g_P^2}}{\bigl|\,1 + g_P(|S_{22}|^2 - |\Delta|^2)\,\bigr|}, \qquad g_P = \frac{G_P}{|S_{21}|^2}$$

令 $R_P = 0$ — 也就是根號內判別式為零：

$$|S_{12}S_{21}|^2 g_P^2 \;-\; 2K|S_{12}S_{21}|\,g_P \;+\; 1 \;=\; 0$$

解這個關於 $g_P$ 的二次方程：

$$g_P \;=\; \frac{K \pm \sqrt{K^2 - 1}}{|S_{12}S_{21}|}$$

取較小的根（較大的根對應「負半徑」非物理區），再乘上 $|S_{21}|^2$：

$$\boxed{\;G_{P,\max} \;=\; \frac{|S_{21}|}{|S_{12}|}\Bigl(K - \sqrt{K^2 - 1}\Bigr)\;}$$

這正是 maximum available gain（$G_{MAG}$）。只有 $K > 1$（unconditionally stable）時存在；否則 $\sqrt{K^2-1}$ 為虛數 — 這也是為什麼 conditionally stable 元件沒有定義 MAG。

一句話直覺

每個 gain 圓是某個 gain 值對應的「$\Gamma_L$ 菜單」。要的增益越高，菜單越短。到了 max gain，菜單只剩一道菜 — 就是 conjugate-match 點 $\Gamma_{ML}$。再要更多，菜單就空了。

為什麼 input 與 output 圓同時縮成點？

在 max available gain 時，元件處於 simultaneous conjugate match：$\Gamma_S = \Gamma_{MS}$ 且 $\Gamma_L = \Gamma_{ML}$，同時滿足 $\Gamma_{in} = \Gamma_S^*$ 與 $\Gamma_{out} = \Gamma_L^*$。由於 $S_{12}$ 造成輸入／輸出兩端耦合，你不能只把 output 圓收成點而 input 圓還是有限大 — 它們會在同一個增益值同時達到半徑零。這就是投影片寫「input or output」的原因。

▸ MAG 是什麼？（Maximum Available Gain）

定義

MAG (Maximum Available Gain) = 一個雙端口元件（通常是電晶體）在同時共軛匹配 (simultaneous conjugate match) 下能達到的最大功率增益。

公式：

$$G_{MAG} = \frac{|S_{21}|}{|S_{12}|}\Bigl(K - \sqrt{K^2 - 1}\Bigr) \qquad (\text{只在 } K > 1 \text{ 才有定義})$$

「Available」這個字的意思

Available gain $G_A$ 的定義：

$$G_A = \frac{\text{元件能提供給負載的可用功率}}{\text{訊號源能提供給元件的可用功率}}$$

注意「available」意指假設下游已完美共軛匹配取出全部可用功率。所以 $G_A$ 只與 $\Gamma_S$ 有關，與實際 $\Gamma_L$ 無關（因為已假設輸出端取走全部 available power）。

當你把 $\Gamma_S$ 也選到讓 $G_A$ 最大的位置 — 即 $\Gamma_S = \Gamma_{MS}$ — 此時兩端同時共軛匹配，這個最大值就是 MAG。

一張表記住三種增益

名稱符號假設公式（最佳化後）
Transducer gain$G_T$實際輸入 + 實際輸出（兩端都可能不匹配）視 $\Gamma_S, \Gamma_L$ 而定
Available gain$G_A$實際 $\Gamma_S$，輸出共軛匹配$\dfrac{|S_{21}|^2 (1-|\Gamma_S|^2)}{|1-S_{11}\Gamma_S|^2 (1-|\Gamma_{out}|^2)}$
MAG$G_{MAG}$輸入與輸出都共軛匹配（$K>1$）$\dfrac{|S_{21}|}{|S_{12}|}(K-\sqrt{K^2-1})$

三者關係：$G_T \le G_A \le G_{MAG}$，等號在對應的匹配條件達成時成立。

為什麼工程上重要

  • MAG 是元件的「增益天花板」：這顆電晶體在這個頻率下，無論你怎麼設計匹配網路，被動匹配能拿到的增益最多就是 MAG。
  • 判斷元件好不好用的數字：datasheet 上看 MAG vs 頻率曲線，就知道這顆元件能用到多高的頻率還有有用的增益。
  • $K = 1$ 時退化成 MSG：$G_{MAG} \to \dfrac{|S_{21}|}{|S_{12}|}$，這是穩定性邊界上的增益上限，conditionally stable 元件加上穩定電路後的目標。
一句話： MAG = 在「兩端同時做共軛匹配」這個最理想條件下，元件能榨出的最大功率增益。它是元件本身的性質（只看 S 參數 + K），跟你選的 $\Gamma_S, \Gamma_L$ 無關 — 因為它已經假設你選了讓兩端同時共軛匹配的那組最佳值。
▸ 為什麼 conditionally stable（$K<1$）元件沒有定義 MAG？

數學上的失效

MAG 公式：

$$G_{MAG} = \frac{|S_{21}|}{|S_{12}|}\Bigl(K - \sqrt{K^2 - 1}\Bigr)$$

當 $K < 1$（conditionally stable）時：

  • $K^2 - 1 < 0$
  • $\sqrt{K^2-1}$ 變成純虛數
  • 整個 $G_{MAG}$ 變成複數 — 沒有「最大可用增益」這個實數值可言

物理意義 — 為什麼會這樣

回到「圓收縮成點」的圖像。當 $K > 1$，把 $G_P$ 一路調高，圓從外往內單調縮小，最後縮到 $\Gamma_{ML}$ 這一點，這時就達到 MAG。

當 $K < 1$ 時，圓不會單調縮小。它會做兩件「壞事」之一：

行為後果
圓越長越大、甚至包含或穿過 Smith 圖的單位圓邊界「對應的最佳 $\Gamma_L$」會跑到 $|\Gamma_L| \ge 1$ 的區域 — 不是被動負載，是要主動補功率
圓本身仍在單位圓內，但 $\Gamma_{out}$ 或 $\Gamma_{in}$ 跑出單位圓元件變成振盪器，不是放大器

換句話說：simultaneous conjugate match $\Gamma_{MS}, \Gamma_{ML}$ 仍然能「形式上」解出來，但這對解落在不穩定區，不是物理上可實現的被動匹配。

一句話

$K > 1$：增益的上限被「圓縮成點」乾淨地定義 → 那個點就是 MAG。
$K < 1$：增益的上限被「穩定性」打斷 → 你能拿到的增益不再受「圓收縮」限制，而是受「不能讓元件振盪」限制 → MAG 失去意義。

替代品 — MSG（Maximum Stable Gain）

conditionally stable 時，工程上改用：

$$G_{MSG} = \frac{|S_{21}|}{|S_{12}|}$$

這正好是 MAG 公式中令 $K = 1$ 時的值（$\sqrt{K^2-1} = 0$）。意義是：如果你能用外加電阻把元件穩到 $K = 1$ 的邊界，最多就能拿到這麼大的增益。再高就要犧牲穩定性。

所以實務上 conditionally stable 元件的設計步驟：

  1. 先加 stabilizing resistor / feedback，把 $K$ 拉到 $> 1$
  2. 然後對穩定後的元件計算 MAG
  3. 或直接接受 MSG 作為設計上限
▸ 為什麼 $g_A = G_A / |S_{21}|^2 > 1$ typically？

先理解 $|S_{21}|^2$ 的物理意義

$|S_{21}|^2$ 是 transducer gain $G_T$ 當兩端都用 $Z_0$ 直接終接（$\Gamma_S = 0,\;\Gamma_L = 0$）時的值：

$$G_T \Big|_{\Gamma_S=0,\;\Gamma_L=0} = |S_{21}|^2$$

也就是「完全不做匹配」、訊號源直接 50 Ω 接元件、負載也直接 50 Ω 的最陽春情況。

為什麼 available gain 一定比這個大

$G_A$ 的定義是：實際 $\Gamma_S$、但輸出已被共軛匹配（負載端拿走全部 available power）。所以即使你還沒對輸入做匹配（$\Gamma_S = 0$），$G_A$ 已經包含一個「輸出匹配補償」：

$$G_A \Big|_{\Gamma_S = 0} = \frac{|S_{21}|^2}{1 - |S_{22}|^2}$$

因為當 $\Gamma_S = 0$ 時 $\Gamma_{out} = S_{22}$，輸出端的共軛匹配把原本 $\Gamma_L = 0$ 損失的 $(1-|S_{22}|^2)$ 因子還回來。所以：

$$g_A \Big|_{\Gamma_S = 0} = \frac{G_A}{|S_{21}|^2} = \frac{1}{1 - |S_{22}|^2} \;>\; 1$$

這已經保證 $g_A > 1$ — 還沒進輸入匹配。

一個具體例子

設典型 RF 電晶體：$|S_{11}| = 0.6,\; |S_{22}| = 0.5,\; |S_{21}| = 2.5,\; |S_{12}| = 0.1$

$\Gamma_S$ 選法$g_A$ 大致值
$\Gamma_S = 0$（無輸入匹配）$1/(1-0.5^2) = 1.33$
中間某個 gain circle 上$\sim 2$ – $3$
$\Gamma_S = \Gamma_{MS}$（max available）可能 $5$ – $10$

每個 constant-$G_A$ 圓對應一個 $g_A$ 值；你要畫的圓是讓 $G_A$ 達到某個目標 $G_{Ak}$，所以 $g_A = G_{Ak}/|S_{21}|^2$ 自然 $> 1$。

為什麼這個歸一化有用

直接用 $G_A$（線性比）會跟元件特性混在一起；除以 $|S_{21}|^2$ 後得到的 $g_A$ 是「相對於零匹配基準，多賺多少倍」這個無因次的量。

圓心、半徑公式（bilateral 情形）：

$$C_A = \frac{g_A\,C_1^*}{1 + g_A(|S_{11}|^2 - |\Delta|^2)}, \qquad R_A = \frac{\sqrt{1 - 2K|S_{12}S_{21}|g_A + |S_{12}S_{21}|^2 g_A^2}}{\bigl|1 + g_A(|S_{11}|^2 - |\Delta|^2)\bigr|}$$

可以看到所有公式直接吃 $g_A$ 而非 $G_A$ — 把 $|S_{21}|^2$ 抽出來後，剩下的部分只跟匹配狀態相關，公式形式乾淨。

一句話： $|S_{21}|^2$ = 完全不做匹配的「裸增益」基準。$g_A$ = 你的目標增益相對這個基準的倍數。只要你的目標比裸接 50 Ω 還好（這幾乎一定成立，因為光是輸出共軛匹配就能擠出 $1/(1-|S_{22}|^2)$ 倍的提升），$g_A$ 就 $> 1$。

例外（$g_A < 1$ 何時發生）

只有當你故意選一個比 $|S_{21}|^2$ 還差的目標增益（例如為了極寬頻寬或極好雜訊匹配而犧牲增益），$g_A$ 才會 $< 1$。這種設計在 LNA 中偶爾出現，在一般 amplifier 設計中很少 — 所以投影片才寫「typically」而不是「always」。

  • $\Gamma_s$、$\Gamma_l$：外部，設計者控制，是你給電晶體看的阻抗。
  • $\Gamma_{in}$、$\Gamma_{out}$：內部，電晶體本身（加上另一側負載）呈現的反射，是電晶體呈現給外部電路的阻抗。
